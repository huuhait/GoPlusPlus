## Decision changes

- 2026-10-28 (P03.17 review, owner decisions, ADR-0018 amendment): `Option[T]` is comparable when `T` is (both nil, or both set and equal; `Option[*T]` by address; `comparable`, struct fields and map keys follow; a non-comparable `T` allows only `== nil`; `o == 5` means `o == Option[int](5)`). A copy of a narrowed `Option` takes the value type (`if a != nil { p := a }` gives `*Node`; `var p Option[*Node] = a` stays an `Option`). Amendment points 3 and 4 (task P03.18): funcs and interfaces with methods are never nil like pointers (`error` and its aliases, `any`, `unsafe.Pointer`, maps, slices and channels keep `nil`; `Option[Logger]` / `Option[func()]` are the maybe forms; `@Required` on a func or method-interface field is an error), and flow typing also covers `v, err := f()` and the comma-ok forms when the value type has no zero value, and the known-non-nil stores into `error`/`any`/map/chan `@Required` fields.

- 2026-10-27 (ADR-0009, P03.02 spike): constant floats are exact rationals on `APInt` with a 512-bit binary float past 4096 bits, like `go/constant`; libbf is not vendored (D3.2).
- 2026-10-27 (P03.07 review, manager decisions): a field or element of an owned temporary is itself a temporary and can move out; through a `Shared[T]` temporary it is a place, and a ref into it is a ref into a temporary. A conversion that shares storage (same underlying owning type ignoring tags, to an interface, or through a type parameter) is checked as its operand; slice→array of owning elements needs ownership. Spec: EXP-2.
- 2026-10-27 (ADR-0007, build profiles): `//gopp:build` terms include the main module's active profile name (P06 D6.12).
- 2026-10-27 (ADR-0006, P01.15 owner decisions): constraints `Copy` and `Clone` (replace `trivial` and `clonable`), the `x.Clone()` method and `IsNil()` on every pointer kind, the `&d` range form, the loop-variable redeclaration error, `func f!() error` is an error, and returning a `ref` into a local is an error. Details in P01 D1.4, D1.8, D1.10, D1.21.

- P03.18 and the last two exit criteria (done, team build `p03-finish`, merged from three coders): `neverNilKind(T)` (Predicates.cpp) is the one "never nil" predicate: the pointer kinds, funcs, and interfaces with methods other than `error` (by identity, so `type E = error` keeps nil, while `type MyErr error` and `interface{ error; Code() int }` are never nil); `hasNil`, `ZeroQuery`, `@Required` (E0348), the `nil` checks (E0347) and the conversions ask it. Checked results (`v, err := f()` for every call whose type ends in `error`, and `m[k]`, `<-ch`, `o.Get()`, `x.(T)`) reuse the Option facts: `FlowState::Pend` holds the locals that may be invalid, each tied to its err / ok, and a condition on the guard is a fact about them (E0350 at a use). The soundness audit is the comment at the end of Flow.cpp, one place per way: reassigning or shadowing v or the guard, a guard a literal assigns or whose address is taken, loops and a for loop's post statement (a value the loop rebinds in a form is pending at the head, tied to its guard only when every form names the same guard: `flowRebound`, also for a variable that becomes a checked result only inside the loop), goto labels (loops and labels are regions: before the body a multi-value assignment only makes its value *tentatively* pending, and whether it is a checked form comes from `noteGuardedForm` on the typed statement; tentative uses are decided at the end of the body, `flowDecideTentative`), stores into non-locals (also an `&` range alias) and spread calls `h(f())` (E0351), and a reference into `v` (`&v`, a pointer-receiver method value, ...) kept across a form that binds `v` again (E0351), and a pointer-receiver method call or method value on the guard or a narrowed local (same as `&x`).
